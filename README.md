# 太虚道卷 使用指南

**版本：v1.08**

## 登录
输入道号和神纹即可入卷；新道号自动注册，初始灵石 10。  
例：道号“云逸”，神纹“123456”。

## 主面板
显示道号、道龄、境界、灵石和修为进度。  
例：炼气期3层，修为值 25。

## 修炼
点击属性卡开始修炼，完成后填写痕迹，属性 +1、修为 +1。  
例：点击“智力”，修炼1小时后填“读完一章”，智力 +1。

## 修仙四艺
选择一项，输入名称和品质，获得对应灵石。  
例：研习功法《基础吐纳》下品，+3 灵石。

## 云游四海
消耗 10 灵石开启副本，填写信息；完成副本获得修为。  
例：开初级游历《减肥10斤》，完成 +30 修为。

## 修行日志
自动记录所有修炼、四艺、游历操作，按时间倒序展示。

## 折叠面板
点击底部双尖括号图标，可收起/展开四艺或云游模块。

## 境界
- 炼气期：0 ~ 999  
- 筑基期：1000 ~ 2999  
- 金丹期：3000+
