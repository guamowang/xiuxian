# 太虚道卷 使用指南

## 用法说明
本系统主要用于帮助用户记录自我提升的行为、成果，按修仙概念做了转换包装、呈现。类似于记账系统，用户自觉保证记录的真实性，纯做数据攀比无甚意义。
例：  
- 看书1小时后，可在系统中记录完成一次智力修炼，增加修为。  
- 看完一本书，可在系统中记录完成一本功法修炼，获取灵石。
- 消耗灵石开启一个3个月的减肥计划（创建副本），在到期前完成可获得修为。

## 登录
输入道号和神纹即可入卷；新道号自动注册，初始灵石10。  
例：道号“云逸真人”，神纹“123456”。

## 修炼
点击属性卡开始修炼，实际进行1小时后点击修炼完成，填写修炼痕迹，属性+1、修为+1。  
例：点击“智力”，修炼1小时后填“阅读《与时间做朋友》”，智力+1、修为+1。 

## 修仙四艺
获取一项成果后，选择修仙四艺中的类型，输入名称，自行判断根据难度选择品质，获得对应灵石。  
例：研习功法《与时间做朋友》，选择下品，灵石+3。

## 云游四海
消耗10灵石开启副本，填写有截止日期的计划内容；自行判断根据难度选择游历级别，按时达成目标后获得修为。  
例：开初级游历《3个月减肥10斤》，完成后修为+30。
